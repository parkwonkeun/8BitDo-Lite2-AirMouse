# 8BitDo Lite 2 AirMouse

**r57부터 이 공개 배포본의 S·D 무선 연결은 Bluetooth Low Energy(BLE)를 사용합니다.** S는 앱 없이 쓸 수 있는 자이로·스틱 마우스와 키보드이고, D는 BLE 게임패드입니다. 같은 패드가 모드에 따라 서로 다른 이름과 BLE 주소로 연결됩니다.

**이전 버전을 썼다면 새로 페어링하기 전에 휴대폰·태블릿 또는 PC의 블루투스 설정에서 이 패드의 기존 등록을 삭제하세요.** 아래 안내대로 S에서 **Lite2 Air Mouse**, D에서 **Lite2 GamePAD**를 각각 한 번 등록합니다. 펌웨어 설치에는 Windows PC와 D 모드 USB 연결이 필요합니다.

## 1. D 모드 USB로 펌웨어 업데이트

1. **8BitDo Lite 2** 모델인지 확인합니다. Windows x64 PC에서 Windows 키트의 압축을 폴더에 모두 풉니다. 처음 실행할 때는 인터넷 연결이 필요합니다.
2. 다른 8BitDo 패드를 분리하고, Lite 2 **상단 스위치를 D로 옮긴 다음** 데이터 전송이 되는 USB 케이블로 PC에 연결합니다. 이미 S로 꽂혀 있었다면 D로 바꾼 뒤 케이블을 다시 꽂습니다.
3. 압축을 푼 폴더에서 **Update.cmd**를 실행합니다. 프로그램이 제조사 서버에서 순정 v1.06과 Windows 업데이트 구성 요소를 받아 SHA-256을 대조하고, 동봉된 변경분으로 r57 이미지를 만듭니다. Python을 설치할 필요는 없습니다.
4. 프로그램이 D 모드 Lite 2 한 대를 찾으면 콘솔에 **R57**을 입력하고 Enter를 누릅니다. **Update complete**가 표시될 때까지 패드 전원과 케이블을 유지합니다. 이 메시지는 기록 진행률 100%와 재시작 후 D 모드 USB 응답까지 확인했다는 뜻입니다.
5. 케이블을 뽑고 아래의 두 가지 블루투스 등록을 진행합니다.

이 프로젝트는 8BitDo 비공식 펌웨어입니다. 기록 중 전원이 끊기면 패드가 시작되지 않을 수 있습니다. 공식 상태로 돌아갈 때는 제조사 업데이터에서 **Lite 2**용 공식 버전을 선택합니다. 이 프로젝트에서 순정으로 복구하는 전 과정은 실기 검증 전입니다. [8BitDo 공식 업데이터](https://support.8bitdo.com/firmware-updater.html)

## 2. 기존 등록 삭제 후 S와 D 페어링

1. 패드 USB를 빼고 전원을 끕니다. 연결할 Android 기기의 **설정 → 블루투스 → 등록된 기기**에서 이 패드의 예전 항목을 눌러 **등록 해제**합니다. Windows에서는 **설정 → Bluetooth 및 장치 → 장치 제거**를 사용합니다. 예전 이름으로는 `8BitDo Lite 2`, `Lite2 Air Mouse Plus`, 시험판의 `Lite2 BLE`와 `Lite2 Pad`가 있습니다. 같은 이름의 패드가 두 대라면 업데이트한 패드의 항목만 삭제하세요. 이전 시험판에서 현재 이름으로 이미 등록했어도 해당 항목을 지우고 새로 등록하세요.
2. **S 모드**로 옮기고 HOME을 짧게 눌러 켭니다. 상단 페어링 버튼을 약 3초간 눌러 아래 LED 네 개가 함께 깜빡이면, **새 기기 페어링**에서 **Lite2 Air Mouse**를 선택합니다. 패드를 잠시 가만히 두었다가 돌려 포인터가 움직이는지 확인합니다.
3. **D 모드**로 옮겨 상단 페어링 버튼을 다시 길게 누릅니다. 기기 목록에서 **Lite2 GamePAD**를 선택합니다. 게임이나 패드 테스트 앱에서 스틱과 방향키를 확인합니다. Lite 2 Control의 모니터를 열어 두었다면 먼저 설정 탭으로 이동하거나 앱 화면을 닫으세요.

새로 등록한 두 항목은 모두 유지하세요. 이후 S·D 스위치를 바꾸면 해당 모드의 등록으로 다시 연결됩니다. r57의 무선 전원 종료는 HOME을 약 2초 누르도록 설정되어 있습니다.

## S 모드에서 패드 사용하기

L/R 버튼이 있는 앞쪽 모서리를 화면 쪽으로 향합니다. **왼쪽 스틱 클릭(L3)**으로 아래 LED와 포인터 입력 방식을 함께 바꿉니다.

| 아래 LED | 동작 |
| --- | --- |
| 1 · 자동 | 자이로로 시작합니다. 왼쪽 스틱을 절반 이상 기울이면 스틱으로 전환됩니다. 중앙으로 놓은 뒤 최소 2초가 지나고 패드를 좌우나 상하로 흔들면 자이로로 돌아갑니다. |
| 2 · 스틱 전용 | 왼쪽 스틱의 기울기로 이동 속도를 조절합니다. 자이로가 커서를 움직이지 않습니다. |
| 3 · 자이로 전용 | 패드의 회전으로 커서를 움직입니다. 오른쪽 스틱 클릭(R3) 후 가만히 놓으면 영점을 다시 잡습니다. |

| 기본 조작 | 기능 |
| --- | --- |
| Y / X | 마우스 왼쪽 / 오른쪽 클릭 |
| B / A | Enter / Android 뒤로 |
| 십자 방향키 | 키보드 ↑ ↓ ← → |
| ★ / 전원 버튼 짧게 눌렀다 떼기 | Android 홈. 전원을 길게 누르면 패드가 꺼집니다. |
| 오른쪽 스틱 위·아래 | 스크롤. 많이 기울일수록 빨라집니다. |
| LT / RT (S 모드 RAW) | LT는 감도를 낮추고 RT는 높입니다. 오른쪽 스틱을 기울이면 휠, 스틱으로 포인터를 조작하면 스틱, 자이로로 조작하면 자이로 감도를 조절합니다. USB와 무선 감도는 각각 저장됩니다. |
| LT / RT (S 슬롯) | 같은 상대 증감 규칙을 사용하며 현재 자이로 또는 스틱 감도를 해당 슬롯에 저장합니다. 스틱 속도는 편집한 곡선에 곱해집니다. |
| 슬롯 전환 (버튼 할당) | 한 버튼으로 RAW → 슬롯 1 → 2 → 3 → RAW를 반복합니다. 원하는 버튼에 ‘슬롯 전환’을 지정하고 저장하면 같은 모드의 모든 슬롯에서 사용할 수 있습니다. |
| − / + (S 슬롯) | 입력 도우미 연결 시 이전 / 다음 슬롯. RAW → 슬롯 1 → 2 → 3 → RAW 순으로 순환합니다. |
| LB / RB | S 모드 RAW와 S 슬롯의 기본값은 LB가 볼륨 내리기, RB가 볼륨 올리기입니다. RAW는 앱 없이 작동합니다. 모니터에서 두 버튼을 함께 3초 누르면 앱 화면이 닫힙니다. |

자이로로 클릭할 때는 손떨림을 줄이도록 좌·우 클릭 직후 자이로 이동을 최대 0.2초 멈춥니다. 그 전에 버튼을 떼면 바로 풀리고, 계속 누르면 시간이 지난 뒤 드래그할 수 있습니다. RAW에서는 이 동작이 기본이며 앱 슬롯에서는 끌 수 있습니다.

## 3. Android 앱과 슬롯 설정

**RAW**는 패드가 직접 보낸 마우스 이동을 그대로 사용합니다. **슬롯 1~3**은 Android 입력 도우미가 감도와 곡선을 적용합니다. 태블릿의 시스템 마우스 속도 설정을 바꿀 필요가 없습니다.

1. Windows에서 Android 키트를 모두 풉니다. PC에 adb가 없다면 Google의 **SDK Platform-Tools for Windows**를 받아 압축을 풀고, 키트 안에 `platform-tools\adb.exe`가 있도록 둡니다. [Google Platform-Tools](https://developer.android.com/tools/releases/platform-tools)
2. 태블릿의 개발자 옵션에서 **USB 디버깅**을 켜고 태블릿을 PC USB에 연결합니다. 태블릿에 나타나는 이 PC의 디버깅 허용 요청을 승인합니다. 패드는 S 모드 블루투스로 태블릿에 연결합니다.
3. **Start-Android.cmd**를 실행합니다. APK를 설치하고 ARM64 입력 도우미를 시작한 뒤 앱을 엽니다. 이때부터 태블릿 USB 케이블은 뽑아도 됩니다. 태블릿을 재부팅하면 이 단계에서 도우미를 다시 시작할 수 있습니다. Android 11 이상 ARM64 기기는 앱의 **설정 → 태블릿에서 입력 도우미 연결**에서 무선 디버깅으로 시작하는 방법도 제공합니다. [태블릿 단독 연결 절차](docs/SLOT-CALIBRATION.md) 다른 앱 위에 슬롯 변경을 표시하려면 Lite 2 Control의 **다른 앱 위에 표시** 권한을 허용합니다.

앱 상단에는 연결 모드와 활성 슬롯이 표시됩니다. **설정**에서 슬롯을 고르고 자이로 최대 감도를 0~2000%로 조절합니다. 기본은 100%이며 선형으로 적용됩니다. S 모드 왼쪽 스틱의 기본 곡선은 데드존 15%, 최대 출력 50%입니다. 양 끝점과 내부 조절점 1~5개로 응답 곡선을 편집할 수 있습니다. 점 옆은 출력값이고 가로축은 스틱 기울기입니다. 편집 중 S 슬롯의 변경을 실제 포인터로 시험한 뒤 우상단에서 저장합니다. 버튼 할당은 패드 그림에서 해당 버튼을 누릅니다.

**모니터**는 큰 패드 그림에 버튼과 스틱 기울기를, 작은 3D 패드에 가속도·자이로로 추정한 자세를 표시합니다. 패드를 정면으로 잡고 **정면 맞추기**를 누르면 현재 방향을 기준으로 삼습니다. 입력 도우미가 연결된 동안 모니터는 패드 입력을 받아 실제 포인터 이동과 클릭을 막습니다. 다음 조합은 **모니터 화면에서 두 버튼을 함께 3초간** 눌러 사용합니다.

| 조합 | 결과 |
| --- | --- |
| **＋와 −** | 설정 탭으로 이동 |
| **LB와 RB** | 모니터와 앱 화면 종료 |

**D 모드**의 프로필 순서는 **RAW → Xbox → Switch → 슬롯 1 → 슬롯 2 → 슬롯 3 → RAW**입니다. ★의 기본 동작은 다음 슬롯 전환입니다. Xbox와 Switch에서는 ★만 재할당할 수 있습니다. 아래 표는 Lite 2를 평소처럼 잡았을 때 게임에 전달되는 버튼입니다.

| D 프로필 | 아래 | 오른쪽 | 왼쪽 | 위 |
| --- | --- | --- | --- | --- |
| Xbox | A | B | X | Y |
| Switch | B | A | Y | X |

Xbox·Switch·슬롯 1~3의 양쪽 스틱 기본 곡선은 데드존 10%, 최대 출력 100%입니다. 슬롯 1~3에서는 게임패드 버튼 배치도 바꿀 수 있습니다. D RAW에서는 패드가 보낸 스틱 축을 그대로 사용합니다. 앱에서 **설정 → 앱 업데이트**를 누르면 GitHub의 새 APK를 확인하고, 새 버전이 있을 때 Android 설치 확인 화면을 엽니다.

## 확인한 범위

기기별 보정값을 유지한 r57을 Lite 2 한 대에 기록한 뒤 재시작과 D 모드 USB 응답을 확인했습니다. 공개 r57에는 기본 스틱 중립값이 들어 있으며 실행 코드는 실기 설치본과 같습니다. Android 앱 0.3.38은 Lenovo Legion Tab Y700 4세대에서 설치와 설정 화면을 확인했습니다.

펌웨어 소스는 `src/`, Android 앱과 입력 도우미는 `android/`, Windows 업데이터와 패키징 도구는 `tools/`에 있습니다. [빌드 절차와 해시](docs/BUILD.md)
