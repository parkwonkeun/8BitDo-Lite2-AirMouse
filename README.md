# Lite2 AirMouse

8BitDo Lite 2를 평소처럼 양손으로 잡고 Android 화면을 가리키는 에어마우스로 사용할 수 있습니다. 상단 스위치를 **S**에 두면 자이로·스틱 마우스와 키보드가 되고, **D**에 두면 기존 게임패드로 돌아갑니다. S 모드의 기본 마우스는 앱 없이도 작동합니다.

**처음 설치할 때는 두 가지를 기억하세요. 펌웨어는 반드시 D 모드에서 Windows PC에 USB로 연결해 업데이트합니다. 업데이트 후 Android에는 S 모드와 D 모드를 각각 한 번씩 블루투스에 등록합니다.**

[최신 릴리스와 다운로드](https://github.com/parkwonkeun/lite2-airmouse/releases/latest) · [소스에서 빌드하기](docs/BUILD.md)

r33은 가속도계와 자이로로 중력 방향을 추정합니다. 패드를 눕히거나 세워 잡아도 바닥에서 하늘로 향하는 축을 중심으로 돌리면 커서가 좌우로 움직입니다. 공개 펌웨어에는 네 스틱 축의 기본 중립값만 들어 있습니다.

앱 0.3.15에서는 **설정 → 스틱 보정**을 눌러 슬롯별 영점과 최대 범위를 조절합니다. 슬롯 사용 중에는 LB로 미디어 볼륨을 올리고 RB로 내립니다. **버튼 할당**에서 다른 버튼으로 옮길 수 있습니다. [태블릿에서 슬롯 보정하기](docs/SLOT-CALIBRATION.md)

## 1. D 모드 USB로 펌웨어 업데이트

1. **8BitDo Lite 2** 모델인지 확인합니다. Windows x64 PC에서 Windows 키트의 압축을 폴더에 모두 풉니다. 처음 실행할 때는 인터넷 연결이 필요합니다.
2. 다른 8BitDo 패드를 분리하고, Lite 2 **상단 스위치를 D로 옮긴 다음** 데이터 전송이 되는 USB 케이블로 PC에 연결합니다. 이미 S로 꽂혀 있었다면 D로 바꾼 뒤 케이블을 다시 꽂습니다.
3. 압축을 푼 폴더에서 **Update.cmd**를 실행합니다. 프로그램이 제조사 서버에서 순정 v1.06과 Windows 업데이트 구성 요소를 받아 SHA-256을 대조하고, 동봉된 변경분으로 r33 이미지를 만듭니다. Python을 설치할 필요는 없습니다.
4. 프로그램이 D 모드 Lite 2 한 대를 찾으면 콘솔에 **R33**을 입력하고 Enter를 누릅니다. **Update complete**가 표시될 때까지 패드 전원과 케이블을 유지합니다. 이 메시지는 기록 진행률 100%와 재시작 후 D 모드 USB 응답까지 확인했다는 뜻입니다.
5. 케이블을 뽑고 아래의 두 가지 블루투스 등록을 진행합니다.

이 프로젝트는 8BitDo 비공식 펌웨어입니다. 기록 중 전원이 끊기면 패드가 시작되지 않을 수 있습니다. 공식 상태로 돌아갈 때는 제조사 업데이터에서 **Lite 2**용 공식 버전을 선택합니다. 이 프로젝트에서 순정으로 복구하는 전 과정은 실기 검증 전입니다. [8BitDo 공식 업데이터](https://support.8bitdo.com/firmware-updater.html)

## 2. Android에 S와 D를 각각 블루투스로 등록

한 모드의 등록만으로 다른 모드까지 등록되지는 않습니다. PC USB를 뺀 상태로 Android의 **설정 → 블루투스 → 새 기기 페어링**에서 다음 두 절차를 한 번씩 진행하세요.

| 순서 | 패드에서 | Android에서 |
| --- | --- | --- |
| **① S 등록** | 스위치를 S로 옮기고 HOME으로 켭니다. 상단 페어링 버튼을 약 3초 눌러 LED가 빠르게 깜박이게 합니다. | **Lite2 Air Mouse Plus**를 선택합니다. 패드를 약 2초간 가만히 놓은 뒤 화면을 향해 돌려 포인터 이동을 확인합니다. |
| **② D 등록** | 패드를 끄고 스위치를 D로 옮긴 뒤 HOME으로 켭니다. 페어링 버튼을 다시 약 3초 누릅니다. | **8BitDo Lite 2** 게임패드 항목을 선택합니다. 게임패드 입력을 지원하는 앱에서 왼쪽 스틱이나 방향키를 확인합니다. |

이후에는 사용할 모드로 바꿔 켜면 됩니다. 예전 S 모드 등록 때문에 포인터만 움직이고 키보드나 휠이 제대로 동작하지 않으면, Android에서 기존 S 항목을 삭제하고 **S 등록**을 다시 진행합니다. S 무선 연결은 Bluetooth Classic HID를 사용합니다.

## S 모드에서 패드 사용하기

L/R 버튼이 있는 앞쪽 모서리를 화면 쪽으로 향합니다. **왼쪽 스틱 클릭(L3)**으로 아래 LED와 포인터 입력 방식을 함께 바꿉니다.

| 아래 LED | 동작 |
| --- | --- |
| 1 · 자동 | 자이로로 시작합니다. 왼쪽 스틱을 절반 이상 기울이면 스틱으로 전환됩니다. 중앙으로 놓은 뒤 최소 2초가 지나고 패드를 좌우나 상하로 흔들면 자이로로 돌아갑니다. |
| 2 · 스틱 전용 | 왼쪽 스틱의 기울기로 이동 속도를 조절합니다. 자이로가 커서를 움직이지 않습니다. |
| 3 · 자이로 전용 | 패드의 회전으로 커서를 움직입니다. 오른쪽 스틱 클릭(R3) 후 가만히 놓으면 영점을 다시 잡습니다. |

| 기본 조작 | 기능 |
| --- | --- |
| Y / X | 마우스 왼쪽 / 오른쪽 클릭 |
| B / A | Enter / Android 뒤로 |
| 십자 방향키 | 키보드 ↑ ↓ ← → |
| ★ / 전원 버튼 짧게 눌렀다 떼기 | Android 홈. 전원을 길게 누르면 패드가 꺼집니다. |
| 오른쪽 스틱 위·아래 | 스크롤. 많이 기울일수록 빨라집니다. |
| LT / RT | 앱과 입력 도우미 연결 시 이전 / 다음 슬롯. RAW → 슬롯 1 → 2 → 3 → RAW 순환을 지원합니다. |
| LB / RB | 슬롯에서 LB는 미디어 볼륨 올리기, RB는 내리기입니다. 모니터에서 두 버튼을 함께 3초 누르면 앱 화면이 닫힙니다. |

자이로로 클릭할 때는 손떨림을 줄이도록 좌·우 클릭 직후 자이로 이동을 최대 0.2초 멈춥니다. 그 전에 버튼을 떼면 바로 풀리고, 계속 누르면 시간이 지난 뒤 드래그할 수 있습니다. RAW에서는 이 동작이 기본이며 앱 슬롯에서는 끌 수 있습니다.

## 3. Android 앱과 슬롯 설정

**RAW**는 패드가 직접 보낸 마우스 이동을 그대로 사용합니다. **슬롯 1~3**은 Android 입력 도우미가 감도와 곡선을 적용합니다. 태블릿의 시스템 마우스 속도 설정을 바꿀 필요가 없습니다.

1. Windows에서 Android 키트를 모두 풉니다. PC에 adb가 없다면 Google의 **SDK Platform-Tools for Windows**를 받아 압축을 풀고, 키트 안에 `platform-tools\adb.exe`가 있도록 둡니다. [Google Platform-Tools](https://developer.android.com/tools/releases/platform-tools)
2. 태블릿의 개발자 옵션에서 **USB 디버깅**을 켜고 태블릿을 PC USB에 연결합니다. 태블릿에 나타나는 이 PC의 디버깅 허용 요청을 승인합니다. 패드는 S 모드 블루투스로 태블릿에 연결합니다.
3. **Start-Android.cmd**를 실행합니다. APK를 설치하고 ARM64 입력 도우미를 시작한 뒤 앱을 엽니다. 이때부터 태블릿 USB 케이블은 뽑아도 됩니다. 태블릿을 재부팅하면 이 단계에서 도우미를 다시 시작할 수 있습니다. Android 11 이상 ARM64 기기는 앱의 **설정 → 태블릿에서 입력 도우미 연결**에서 무선 디버깅으로 시작하는 방법도 제공합니다. [태블릿 단독 연결 절차](docs/SLOT-CALIBRATION.md) 다른 앱 위에 슬롯 변경을 표시하려면 Lite 2 Control의 **다른 앱 위에 표시** 권한을 허용합니다.

앱 상단에는 연결 모드와 활성 슬롯이 표시됩니다. **설정**에서 슬롯을 고르고 자이로 최대 감도를 0~500%로 조절합니다. 기본은 100%이며 선형으로 적용됩니다. 왼쪽 스틱의 기본 곡선은 데드존 15%, 최대 출력 50%입니다. 양 끝점과 내부 조절점 1~5개로 응답 곡선을 편집할 수 있습니다. 점 옆은 출력값이고 가로축은 스틱 기울기입니다. 편집 중 S 슬롯의 변경을 실제 포인터로 시험한 뒤 우상단에서 저장합니다. 버튼 할당은 패드 그림에서 해당 버튼을 누릅니다.

**모니터**는 큰 패드 그림에 버튼과 스틱 기울기를, 작은 사각형에 자이로 이동을 표시합니다. 입력 도우미가 연결된 동안 모니터는 패드 입력을 받아 실제 포인터 이동과 클릭을 막습니다. 다음 조합은 **모니터 화면에서 두 버튼을 함께 3초간** 눌러 사용합니다.

| 조합 | 결과 |
| --- | --- |
| **＋와 −** | 설정 탭으로 이동 |
| **LB와 RB** | 모니터와 앱 화면 종료 |

**D 모드**에서는 원래 게임패드 입력으로 게임을 플레이할 수 있습니다. 앱은 D 모드 화면에서 입력을 모니터링하고 프로필을 편집·저장합니다. D 프로필의 곡선·버튼 할당을 다른 게임의 입력에 적용하는 기능은 이번 버전에 포함되지 않았습니다.

## 확인한 범위

Lite 2 한 대에 기기별 보정을 유지한 r33을 기록하고 D 모드 USB 재시작 응답을 확인했습니다. 공개 키트는 스틱 중립값을 기본값으로 구성합니다. ARM 모의 시험에서는 같은 수직축 회전을 평면·45도·수직 자세에 입력했을 때 가로 이동량이 같았습니다. 실제 손동작에 따른 자세별 감도는 추가 확인이 필요합니다. Android 앱 0.3.15는 Lenovo Legion Tab Y700 4세대에서 확인했습니다.

펌웨어 C 소스는 `src/`, Android 앱과 입력 도우미는 `android/`, Windows 업데이터와 패키징 소스는 `tools/`에 있습니다. [빌드 절차와 펌웨어 해시](docs/BUILD.md)
