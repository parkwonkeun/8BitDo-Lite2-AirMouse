# 슬롯별 스틱 보정

Lite 2 Control은 태블릿에 S 모드와 D 모드의 슬롯별로 보정값을 저장합니다. 패드를 블루투스로 연결하고 입력 도우미가 연결된 상태에서 진행합니다.

1. **설정**에서 보정할 모드의 슬롯 1, 2, 3 중 하나를 선택합니다.
2. **스틱 보정** 버튼을 눌러 보정 창을 열고 왼쪽 또는 오른쪽 스틱을 고릅니다. S 모드에서 왼쪽 스틱을 측정할 때는 L3를 눌러 아래 두 번째 LED를 켭니다.
3. **영점 측정**을 열고 스틱에서 손을 뗍니다. 중앙값이 안정되어 **적용**이 켜지면 누릅니다.
4. **최대 범위 측정**을 열고 스틱을 바깥 테두리에 붙여 천천히 한 바퀴 돌립니다. 좌우·상하 끝까지 모두 닿은 뒤 **적용**을 누릅니다.
5. 필요하면 다른 스틱에서도 반복하고, 보정 창을 **닫기**로 닫은 뒤 설정 우측 상단 **저장**을 누릅니다. 두 스틱의 X·Y마다 음수 끝, 영점 구간, 양수 끝이 저장됩니다.

영점 구간 안의 입력은 0이며 양쪽 끝은 각각 −100%, +100%로 환산합니다. 감도 곡선은 그다음에 한 번 적용됩니다. S 모드에서는 슬롯 포인터와 휠에 적용되고 D 모드의 Xbox·Switch·슬롯 1~3에서는 입력 도우미가 게임으로 보내는 양쪽 스틱 출력에 적용합니다. RAW는 패드 자체 보정을 사용합니다.

태블릿 재부팅으로 도우미가 종료되면 Android 11 이상 ARM64 태블릿에서 **설정 → 태블릿에서 입력 도우미 연결**을 사용할 수 있습니다. 개발자 옵션에서 무선 디버깅을 켭니다. 처음에는 분할 화면에서 **페어링 코드로 기기 페어링**에 나온 포트와 코드를 앱의 **처음 연결 · 페어링**에 입력합니다. 이어 **입력 도우미 시작**에 무선 디버깅 첫 화면의 연결 포트를 입력합니다. Android가 기존 페어링을 유지하는 동안은 도우미 시작 단계만 반복하면 됩니다.

APK에는 ARM64 입력 도우미와 플랫폼 도구 adb 35.0.2가 포함됩니다. 빌드 스크립트가 배포 파일의 SHA-256을 확인합니다. [Android SDK Tools 배포본](https://github.com/lzhiyong/android-sdk-tools/releases/tag/35.0.2)
